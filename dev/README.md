# Paraveda CRM — هيكل المشروع

## 📁 الملفات

| الملف | شنو فيه |
|---|---|
| `index.html` | الواجهة كاملة (React مبني ومضغوط فملف واحد ~1MB) — هو اللي كترفعو للسيرفر |
| `api.php` | السيرفر/المزامنة (PHP 7.2+): حفظ، نسخ احتياطي، تدقيق، حماية من "الأشباح" |
| `INSTALL.txt` | تعليمات التنصيب على الهوست |
| `public_html.zip` | الحزمة الأصلية اللي وصلات (مضغوطة قبل الاستخراج) |
| `run-local.sh` | تشغيل محلي بنقرة وحدة (كيحتاج غير node/npm) |
| `dev/app_module.pretty.js` | نسخة "مجمّلة" (beautified) من كود الواجهة للقراءة والتحرير |
| `dev/README.md` | هاد الملف |

## 🚀 التشغيل محلياً

```bash
./run-local.sh          # يبدا على http://localhost:8080
```

المزامنة كتخدم كاملة محلياً: الداتا كتسجل فـ `~/crm-paraveda-data/`
(برا من المشروع — متأثرش بالـ git).

- فحص صحة السيرفر:
  `http://localhost:8080/api.php?action=status&token=c6e04cb5de9088be01a685abc243995a80426eba45de2060`
- لائحة النسخ الاحتياطية:
  `http://localhost:8080/api.php?action=backups&token=...`

## ✏️ كيفاش نبدلو فالواجهة

الكود فـ `index.html` مضغوط (minified). الطريقة العملية للتحرير:

1. **التعديل الدقيق**: نقلبو على النص/العنصر لي بغينا نبدلو فـ `index.html`
   (بحال: اسم صفحة، عنوان، نص زر، لون) ونبدلوه بنص جديد بنفس الطول
   أو أقل — minified كيبقى خدام عادي.
2. **نسخة القراءة**: `dev/app_module.pretty.js` فيها نفس الكود مجمّل
   وبالأسطر، صالحة للفهم والبحث — ولّا للتجربة قبل ما نطبقو التعديل.
3. **تعديلات كبار** (صفحة جديدة، ميزة جديدة): خير حاجة هي الكود
   المصدري الأصلي ديال التطبيق (React). إلا عندك → حطو هنا فمجلد
   `src/` ونبنيوه من جديد بكل حرية.
